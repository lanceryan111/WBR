你这个“没有输出”其实很可能是 正常的 204 response，不是失败。

GitHub 官方这个 endpoint：

GET /orgs/{org}/teams/{team_slug}/repos/{owner}/{repo}

如果 team 对 repo 有权限，但你没有指定 repository media type，它可以直接返回：

204 No Content

所以 gh api ... --jq '.permissions' 就会什么都不显示。官方文档明确写了：204 表示 team 对该 repo 有权限；如果没有权限则是 404。

你现在应该强制让 API 返回 repository detail：

gh api \
  -H "Accept: application/vnd.github.v3.repository+json" \
  orgs/TD-Universe/teams/wbr-dev-ops/repos/TD-Universe/watrp-devex-tdmoband \
  --jq '{permissions: .permissions, role_name: .role_name}'

正常 repo：

gh api \
  -H "Accept: application/vnd.github.v3.repository+json" \
  orgs/TD-Universe/teams/wbr-dev-ops/repos/TD-Universe/watrp-devex-tdmobios \
  --jq '{permissions: .permissions, role_name: .role_name}'

你重点比较：

{

如果两个 repo 都是：

push: true

那 team permission 基本也可以排除。
